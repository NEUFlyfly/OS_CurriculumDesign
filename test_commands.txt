=== 操作系统课程设计 - 文件系统功能测试命令 ===
项目: FlyflyUFS
说明: 以下命令在登录后的 ╰─> 提示符后输入


=== 1. 基础命令测试 ===

help            # 显示所有可用命令
pwd             # 显示当前目录 (/home/root)
ls              # 列出当前目录内容

=== 2. 目录操作测试 ===

mkdir project          # 创建子目录 project
ls                     # 应看到 project
cd project             # 进入 project
pwd                    # 应显示 /home/root/project
mkdir src              # 创建嵌套目录
ls                     # 应看到 src
cd src                 # 进入 src
pwd                    # 应显示 /home/root/project/src

# 测试 ".." 返回上级
cd ..                  # 回到 project
pwd                    # 应显示 /home/root/project
cd ..                  # 回到 root
pwd                    # 应显示 /home/root

# 测试 "." 当前目录
cd .                   # 不动
pwd                    # 还是 /home/root

# 测试 rmdir 删除目录
rmdir project          # 删除 project 目录（需为空）
ls                     # project 应消失

=== 3. 文件操作测试 ===

touch readme.txt       # 创建空文件 readme.txt
ls                     # 应看到 readme.txt
cat readme.txt         # 查看文件内容（空文件无输出）
rm readme.txt          # 删除文件
ls                     # readme.txt 应消失

=== 4. 多级目录 + 文件 ===

mkdir codes
cd codes
touch main.cpp
touch utils.cpp
ls                     # 应看到 main.cpp, utils.cpp
cat main.cpp           # 空文件，无输出
cd ..
ls                     # 应看到 codes
rmdir codes            # 删除（非空目录？如果 rmdir 不允许删非空则跳过）

=== 5. 用户管理测试 ===

useradd testuser       # 添加新用户
exit                   # 退出当前登录
testuser               # 输入新用户名（密码：空或按回车）
pwd                    # 应在 /home/testuser
ls                     # 应看到 . 和 ..
exit                   # 退出

=== 6. root 权限测试 ===

root                   # 重新登录 root
root                   # 密码 root

# root 可以进入任何目录
cd /home/testuser
pwd                    # 应显示 /home/testuser
ls                     # 应看到 testuser 的家目录内容
cd /home/root

userdel testuser       # 删除测试用户

=== 7. 格式化系统（危险！会清空所有数据）===

# format               # 格式化整个文件系统，完成后自动退出

=== 8. 退出系统 ===

exit                   # 退出登录
